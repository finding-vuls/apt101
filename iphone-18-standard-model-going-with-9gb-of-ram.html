iPhone 18 standard model going with 9GB of RAM

    Oliver September 4, 2026

    Instead of keeping 8GB or jumping straight to 12GB, Apple decided to give the iPhone 18 standard model 9GB of RAM—using six 1.5GB memory chips. The real reason behind this odd number? One simple word: AI.

    Sure, 8GB of RAM can run iOS 26 and iOS 27 smoothly enough for everyday use—apps open fast, scrolling is fluid, no complaints there. But when you throw Apple Intelligence into the mix, things get tight.

    According to Apple's docs, its AI comes in two tiers: a basic model called AFM 3 Core, and a more advanced version called AFM 3 Core Advanced.

    The basic model has about 3 billion parameters. It only takes up a few hundred MB when sitting idle in the background, but when it's actually doing something—like generating text or processing an image—it can eat up 2 to 3GB of RAM. At the same time, iOS needs to reserve plenty of memory for system services, core frameworks, third‑party apps, and background tasks. So when you're running several apps at once and one of them triggers AI processing, memory pressure can spike. The system then has no choice but to shut down some background apps—what we call "killing the back‑end."

    That extra 1GB on the iPhone 18 standard model starts to make sense here. It won't unlock the advanced AI model, but it does give the basic AI a "safety buffer." That means smoother performance overall—no stuttering, no crashes, no sudden app closures. The AI and the rest of the system can coexist peacefully for the long haul.

    As for the iPhone 18 Pro, it runs the advanced AFM 3 Core Advanced model, which packs a massive 200 billion parameters. Apple loads different parts of the model as needed, depending on the task, so it usually takes up somewhere between 1 and 4GB of RAM. With 12GB of memory, the Pro has more than enough room to handle it without breaking a sweat.
